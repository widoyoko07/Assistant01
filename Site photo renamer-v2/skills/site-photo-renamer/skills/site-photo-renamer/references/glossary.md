File ini milik user dan boleh ditambah kapan saja. Pakai padanan di sini setiap kali istilah muncul di
caption/chat atau terlihat di foto, supaya nama file konsisten. Istilah belum ada di tabel: pakai terjemahan
umum konstruksi yang paling jelas, lalu catat di daftar pertanyaan dry-run agar user bisa menambahkannya.
Gunakan Title Case. Singkatan proyek (MCC, STP, WWTP, PS) ditulis huruf besar.
